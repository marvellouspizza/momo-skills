# UI Language

Use these UI modules alongside the motion modules.

## NU-001 Giant Narrative Title

The first viewport uses oversized serif display type as a visual material. The H1 should be the brand, object, or literal story theme. Do not add a generic marketing eyebrow by default.

## NU-002 Minimal Header

Use a tiny wordmark left and 2-4 nav items right. Use underline, opacity, or crossfade hover. Avoid heavy nav buttons.

## NU-003 Fixed Glass CTA

Include a bottom fixed pill CTA with translucent glass, subtle border light, an icon or tiny motif, and a short verb phrase. It must have hover and click states.

## NU-004 Circular Sound/Ambient Control

Add a bottom corner circular control. It can toggle real audio or ambient mode. It must visibly show active/inactive state.

## NU-005 Liquid Glass Cursor

Desktop only. Follow the pointer with a circular cursor, rotating inner ring, and optional hover label.

## NU-006 Sparse Narrative Copy

Use short, polished copy with strong whitespace. The site is complete through rhythm, visual scene, and section purpose rather than dense paragraphs.

## NU-007 Dark Final Contact

End with a dark or high-contrast section, final CTA/contact, and footer/social items that reveal with blur/y motion.

## NU-008 Foggy Low-Contrast Background

Base backgrounds should be atmospheric and material-friendly, not plain white. Map user colors to roles: fog background, refraction tint, highlight, particle color, dark field, border light, text.

## NU-009 Noomo-Like Typography

Use a refined serif for large expressive headings and a clean sans for UI/navigation/body. Keep letter spacing at `0` unless a specific tiny label needs mild tracking.

## NU-010 Section As Viewport

Each section should feel like a designed viewport/screen, not a card stack. Cards are allowed only for repeated anchors, cases, or compact principle items.
